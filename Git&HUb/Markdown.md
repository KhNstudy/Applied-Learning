# **Markdown**

## **What is Markdown**
    It is a lightweight markup language created in 2004 that uses simple text formatting symbols, such as:

-**Hashtag** (#) for headings, from the
 first level to the highest possible level for exemplos: 
    * Using the # symbol twice on each end makes the text bold;
    * Usign the # symbol once on each end make the text italic;
    * Usign the # symbol once or twice or more times on the left side of each
    word or phrase you want to turn into a heading and make the text a title;
